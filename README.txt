GISDEVCAN Inc. — website rebuild starter

Files:
- index.html: complete responsive one-page company website
- styles.css: visual design and responsive layouts
- script.js: mobile navigation, product enquiry prefill and email-form handoff

Run locally:
1. Extract the ZIP.
2. Open index.html in a browser, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000.

Before publishing:
- Confirm company address, legal registration details and preferred social links.
- Confirm product list, current availability, specifications, certificates, pricing and delivery terms.
- The enquiry form currently opens the visitor's email application; it is not a server-backed form. Connect a secure form endpoint before production if submissions must be stored.
- Replace image URLs with licensed company-owned imagery if required.
- Verify that the WhatsApp number is active for WhatsApp.
